## 实现约定和安全

- `POST /api/check-dir` 只检查，不创建目录。目录路径先 `realpath`。
- `POST /api/sessions/delete` 只操作 sessions 内的普通、有效 pi JSONL；通过参数数组调用 `trash`。先检查并关闭持有该空闲文件的进程，避免删除后续写。没有 `rm` 或永久删除的备用路径。
- 同一个项目仍在回复时禁止切到另一段/新建；其他项目可以并行。事件带 `sessionPath` 标识回复中的对话。
- 列表在消息保存、`agent_settled`、`session_info_changed` 和删除后刷新；刷新失败显示错误，不冒充成功。
- 改名使用 pi 的 `set_session_name`；改名其他对话先明确打开那个目标，不依赖尚未更新的 React cwd。
- Token 仍只在标签页 sessionStorage；最近项目和列表偏好仅在浏览器本地。草稿仅在当前页面内按对话保存，不串到别的项目。
