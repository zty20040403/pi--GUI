## 排查与修复

第一轮第 5 阶段在明确批准合成项目外的 write 后失败。原因不是新增危险请求，而是原验收脚本在后台确认前，把仍在 DOM 中、按钮已禁用的已回答弹窗当成了新的审批。

修正 `scripts/verify-phase5.ts`：同一次 DOM 读取检查按钮是否可回答、标题和正文；已回答请求不再重复处理。原安全白名单不变，危险操作仍只拒绝，没有扩大自动批准范围。修正后完整第 5 阶段通过。

一次同时运行 npm test 和验收后台产生了 4317 占用失败。随后关闭验收后台，单独重跑类型检查和全部 46 组测试，全部通过。各阶段测试必须串行运行。
